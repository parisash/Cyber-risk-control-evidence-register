# Cyber Risk, Control and Evidence Register

A practical cybersecurity GRC portfolio project that links cyber risks, controls, evidence records, remediation actions and executive-ready reporting.

This project demonstrates how GRC teams can move from static spreadsheets to a more traceable workflow where each risk is connected to a control, evidence requirement, remediation action and governance decision.

## Project Purpose

Cybersecurity GRC work is not only about listing risks. Effective governance requires clear traceability from risk identification through to control ownership, evidence quality, remediation and reporting.

This project demonstrates a practical workflow:

```text
Cyber Risk → Control → Evidence → Remediation → Executive Report
